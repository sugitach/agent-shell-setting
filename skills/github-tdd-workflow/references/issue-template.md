# Issue Template & Checklist

Issue を新規作成、または既存 Issue を補完する際の基準フォーマットです。

## フォーマット

```markdown
## 概要・目的
何のためにどのような機能を追加・修正するかを簡潔に記述。

## 要件 (Requirements)
- [ ] 要件 1: 仕様の具体的な動作
- [ ] 要件 2: 入出力やインターフェースの仕様

## 完了条件 (Definition of Done: DoD)
- [ ] DoD 1: 〇〇のユニットテスト/結合テストが追加されパスしていること
- [ ] DoD 2: 〇〇のエラー時に適切なエラーハンドリングが行われること
- [ ] DoD 3: Lint / 型チェックがエラーなく通過すること
```

## サジェスト（補完）時のポイント
- 要件が1行だけの場合: 具体的な振る舞いやエッジケース、エラー時の動作を補完候補として提示する。
- DoD がない場合: 「どのテストが通過すれば完了とみなせるか」を明記するチェックリストを提示する。
